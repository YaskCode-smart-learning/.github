## ¿Qué es YaskCode Smart Learning?

**YaskCode Smart Learning** es un espacio de experimentación, implementación y portafolio dedicado al diseño de **ecosistemas digitales de aprendizaje**.

Exploramos cómo integrar plataformas educativas, objetos de aprendizaje, diseño instruccional y tecnologías abiertas para construir experiencias formativas que puedan ser administradas, evaluadas, reutilizadas y evolucionadas.

La iniciativa comienza como un **entorno demostrativo y de experimentación aplicada**, con proyectos piloto documentados y reproducibles. A futuro podrá servir también como base para servicios de acompañamiento e implementación de soluciones educativas digitales.

## 🖥️ LMS y Plataformas

Exploramos la instalación, configuración, administración y evolución de plataformas para el aprendizaje digital.

| **Infraestructura y gestión**                                                                                                                                                              | **Experiencia y operación**                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| - arquitectura y despliegue de plataformas LMS;<br>- organización de categorías, cursos y cohortes;<br>- gestión de usuarios, roles y permisos;<br>- seguridad, respaldos y mantenimiento. | - configuración de actividades y recursos;<br>- integración de herramientas educativas;<br>- accesibilidad y experiencia de usuario;<br>- documentación técnica y operativa. |

> Las plataformas concretas se presentan como **tecnologías utilizadas o exploradas**, no como productos propios de YaskCode Smart Learning.

## 📘 Objetos de Aprendizaje

Diseñamos y experimentamos con recursos digitales orientados a objetivos de aprendizaje concretos.

| **Formatos y recursos**                                                                                   | **Estructura y valor educativo**                                                                                 |
| --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| - contenido multimedia;<br>- actividades interactivas;<br>- videos;<br>- infografías;<br>- cuestionarios. | - simulaciones;<br>- recursos H5P;<br>- paquetes interoperables;<br>- metadatos;<br>- evidencias de aprendizaje. |

Buscamos que estos recursos sean **reutilizables**, **accesibles**, **documentados** y **pedagógicamente intencionados**.

## 🎓 Diseño Instruccional

La tecnología se organiza alrededor del aprendizaje, no al contrario.

**Resultado de aprendizaje → Objeto de aprendizaje → Actividad → Evaluación → Evidencia**

| **Diseño pedagógico**                                                                                                                      | **Experiencia y seguimiento**                                                                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| - objetivos y resultados de aprendizaje;<br>- secuencias instruccionales;<br>- actividades;<br>- estrategias de evaluación;<br>- rúbricas. | - retroalimentación;<br>- navegación;<br>- accesibilidad;<br>- seguimiento del progreso;<br>- coherencia entre propósito, contenido y evaluación. |

## Proyecto piloto

### Smart Learning Pilot

El primer proyecto de YaskCode Smart Learning será un **entorno educativo demostrativo** diseñado para documentar de extremo a extremo la construcción de una experiencia de aprendizaje digital.

| **Qué permitirá mostrar**                                                               | **Para qué servirá**                                                                                                                                            |
| --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Plataforma → Curso → Objetos de aprendizaje → Actividades → Evaluación → Evidencias** | Caso de estudio público para demostrar capacidades en administración de plataformas, diseño instruccional, creación de recursos educativos e interoperabilidad. |

> El proyecto se encuentra en fase inicial de diseño. No se presentan todavía implementaciones, resultados o casos institucionales que no hayan sido desarrollados y validados.

## Tecnologías y estándares explorados

YaskCode Smart Learning podrá experimentar progresivamente con tecnologías y especificaciones como:

| **Plataformas y contenidos**           | **Interoperabilidad y ecosistema**       |
| -------------------------------------- | ---------------------------------------- |
| `Moodle LMS` · `WordPress LMS` · `H5P` | `SCORM` · `LTI` · `Google for Education` |

Estas referencias identifican **tecnologías utilizadas o estudiadas** en los proyectos y **no implican asociación, patrocinio, certificación ni representación oficial** de sus respectivos proveedores.

A medida que los proyectos evolucionen podrán incorporarse otras tecnologías relacionadas con interoperabilidad, analítica de aprendizaje, automatización y contenidos educativos digitales.

## Portafolio y experimentación

Los proyectos de Smart Learning buscarán documentar no solamente el resultado final, sino también el proceso:

**Diagnóstico → Diseño → Implementación → Validación → Documentación → Evolución**

| **Qué documentamos**                                                                                                       | **Qué aporta al portafolio**                                                                  |
| -------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| - decisiones de arquitectura;<br>- configuración reproducible;<br>- recursos de aprendizaje;<br>- modelos instruccionales. | - evidencias;<br>- documentación;<br>- aprendizajes y mejoras;<br>- trazabilidad del proceso. |

Esto permite que Smart Learning funcione como un **portafolio técnico-educativo verificable**, además de un espacio para experimentar.
